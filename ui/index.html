About

Scrooge — desktop monitor for AI coding agents.

Session data comes from the open-source abtop collector (MIT, Tae Hwan Jung) extended with GitHub Copilot. Copilot quota uses GitHub's internal copilot_internal/user endpoint and Claude limits use api/oauth/usage: both are undocumented and may change.
